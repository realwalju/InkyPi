Weather, upcoming events, a reminder, and up to three sensor readings on one screen. Every section is optional.

Leave blank to hide. Long reminders are shortened to fit the display.

Weather

Uses Open-Meteo; no API key is required. Copy coordinates from your existing weather plugin or a map.

Calendar

Up to five calendars. Shows the next three events over seven days, including all-day and ongoing events. Uses the timezone and time format in device settings.

MQTT readings

Use the broker configured on the API Keys page. Leave a topic blank to hide that reading. A JSON field can be a dotted path, such as sensor.temperature.
